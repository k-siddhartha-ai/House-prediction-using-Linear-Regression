🏠 House Price Prediction using Linear Regression

Author: K. Siddhartha

This project demonstrates a house price prediction application built using Linear Regression and deployed as an interactive Gradio web app.

The model predicts the house price based on the house size (in square feet).

🚀 Live Demo

👉 https://huggingface.co/spaces/Siddhartha001/House-prediction-using-Linear-Regression

🤗 Hugging Face Profile
https://huggingface.co/Siddhartha001

🧠 Model Overview

Algorithm: Linear Regression

Input Feature: House Size (sqft)

Output: Predicted House Price (in thousands of dollars)

📊 Sample Dataset
House Size (sqft)	Price ($k)
800	40
1000	50
1200	55
1500	70
1800	85
